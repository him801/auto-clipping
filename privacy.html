Privacy Policy

Effective date: 16 November 2026

This policy explains how Auto Clipping (“the app”) handles data. The app is a personal, single-user tool run on its owner's own computer to create highlight clips from the owner's own gameplay livestreams and upload them to the owner's own YouTube channel.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • Basic channel information (channel name and ID) of the signed-in account, via the youtube.readonly scope, only to confirm the app is connected to the correct channel.
  • Upload permission via the youtube.upload scope, used only to upload clips that the owner has manually approved, with their title, description, tags and publish time.
  • The owner's own livestream recordings, downloaded from the owner's own channel to create clips.

The app does not access other users' data, comments, subscribers' personal information, analytics, or any data beyond the above.

How data is stored

  • OAuth tokens, downloaded recordings, generated clips and the app's work log are stored only on the owner's own computer. There is no app server or cloud database.
  • Data is kept only as long as the owner needs it for making clips and can be deleted at any time by deleting the app's folder.
  • The app does not use cookies or tracking on this website.

How data is shared

  • Short, low-resolution excerpts of the owner's own gameplay recordings are sent to the Google Gemini API to suggest highlight moments, subtitles and titles. No YouTube API Data (such as OAuth tokens or channel data) is sent to it.
  • Approved clips are uploaded to the owner's own YouTube channel.
  • No data is sold, shared with advertisers, or shared with any other third party.

Data retention and deletion

  • Retention: data is kept on the owner's computer only as long as it is needed to make and upload clips. Excerpts sent to the Gemini API are deleted from Google's file storage by the app immediately after each analysis.
  • Deleting data: all locally stored data (OAuth tokens, recordings, clips, logs) can be deleted at any time by deleting the app's folder. Deleting the token file alone disconnects the app from YouTube.
  • Revoking access: you can revoke the app's access to your Google account at any time from the Google security settings page. After revocation the app can no longer access YouTube.
  • Deletion requests: email him801@gmail.com and any related data will be deleted within 7 days.

Children

The app is not directed to children and is not intended for use by anyone other than its owner.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
